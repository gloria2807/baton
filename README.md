# Baton

Point, speak, and conduct an orchestra of agents in your own browser.

This repository is being built during the Meta Global AI Developer Hackathon on Muse Spark Open. Start with `SETUP.md`. Claude Code's instructions are in `CLAUDE.md`, the product is described in `docs/SPEC.md`, the build stages are in `docs/BUILD_PLAN.md` and the film is in `docs/DEMO_SCRIPT.md`.

`fixtures/spike/` holds test inputs for the first model check: two short spoken requests made with an offline speech synthesiser (so they sound robotic) and a screenshot of the fictional Ledgerly demo site with numbered marks, plus the expected answers.
